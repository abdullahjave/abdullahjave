<h2 align="center">About</h2>

I'm a Computer Science and AI enthusiast from Pakistan, interested in how machines learn to see. I build computer vision and machine learning projects, from YOLO-based detection and pose pipelines to the dashboards and apps that make them usable. Alongside that, I'm growing a research-oriented computer vision portfolio and collaborating on real-world AI projects. I learn in public, so experiments, notes and lessons end up on GitHub.
